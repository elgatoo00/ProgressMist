1. C'est quoi ProgressMist ?

ProgressMist est un carnet de suivi pour votre recherche d'emploi, de stage, d'alternance, de CDI ou de CDD.

Au lieu de vous perdre dans des dizaines d'offres, vous notez tout au même endroit :

  • 📝 Les offres auxquelles vous avez postulé
  • 📊 Où vous en êtes (en attente, entretien, acceptée...)
  • ⏰ Les relances à faire (et l'appli vous les rappelle !)
  • 📅 Le compte à rebours avant le début de votre stage ou alternance
  • ⚖️ La comparaison de vos offres acceptées (salaire, avantages...)

Tout est sauvegardé dans votre navigateur. Pas besoin de créer un compte.

2. Se repérer dans l'application

Le menu de gauche

C'est votre tableau de bord principal. Vous y trouvez :

  • Les 4 catégories : Stage, Alternance, CDI, CDD — cliquez sur une catégorie pour voir uniquement les candidatures qui la concernent
  • Les pages : Dashboard, Candidatures, Kanban, Tableau, Calendrier, Négociation, Analytics, Entreprises, Paramètres
  • Le bouton « Nouvelle candidature » — pour ajouter une candidature rapidement

La barre du haut

  • Le badge de catégorie (ex: « Stage ») — vous rappelle dans quelle catégorie vous êtes
  • ⏱ Le compte à rebours — jours restants avant le début de votre stage ou alternance
  • ☀️/🌙 — passer du mode clair au mode sombre
  • 🔔 — vos notifications (relances du jour, entretiens...)

3. Ajouter une candidature

Il y a deux façons d'ajouter une candidature :

Le formulaire (tout en un coup)

Cliquez sur « Nouvelle candidature » dans le menu de gauche. Remplissez les champs :

  • Entreprise et Poste (obligatoires)
  • Lieu, Date, Moyen (LinkedIn, Indeed, email...)
  • Contact (nom, email, téléphone du recruteur)
  • Documents envoyés (CV, lettre, portfolio...)
  • Relances — voulez-vous être rappelé de relancer ? Dans combien de jours ?
  • Notes personnelles

Puis cliquez sur « Enregistrer ».

L'assistant (question par question)

Vous préférez répondre à des questions une par une ? Cliquez sur « Assistant ». L'application vous guide pas à pas :

  1. Quel type de contrat ?
  2. Le nom de l'entreprise ?
  3. L'intitulé du poste ?
  4. Où ?
  5. Quand avez-vous postulé ?
  6. Par quel moyen ?
  7. Le lien de l'offre ?
  8. Un contact ?
  9. CV envoyé ? Lettre ?
  10. Est-ce rémunéré ?
  11. Voulez-vous une relance automatique ?
  12. Des notes ?

À la fin, votre fiche est créée automatiquement. Vous pouvez revenir en arrière à tout moment.

💡 Lequel choisir ? Le formulaire si vous voulez tout remplir d'un coup. L'assistant si vous préférez être guidé, surtout sur téléphone.

4. Voir ses statistiques (Dashboard)

Le Dashboard est la première page que vous voyez. Il vous montre :

  • Le nombre total de candidatures
  • Combien sont en attente, en entretien, acceptées, refusées
  • Votre taux de réponse — quel pourcentage d'entreprises vous a répondu
  • Les relances du jour — qui devez-vous recontacter aujourd'hui ?
  • Les entretiens à venir
  • Un graphique qui montre la répartition de vos candidatures

5. Consulter une candidature

Cliquez sur n'importe quelle candidature pour ouvrir sa fiche détail. Vous y verrez :

  • Toutes les informations que vous avez remplies
  • Le statut actuel (à droite) — vous pouvez le changer en un clic
  • Les relances — la prochaine date prévue, le nombre déjà fait
  • L'historique — tout ce qui s'est passé sur cette candidature
  • Les pièces jointes — vous pouvez ajouter votre CV, lettre de motivation, etc.

Modifier ou supprimer

  • Modifier : bouton « Modifier » en haut à droite
  • Supprimer : icône 🗑️ en haut à droite, puis confirmez

6. Changer un statut

Chaque candidature a un statut. Voici les 7 statuts possibles :

  • 🔵 À préparer — vous avez repéré l'offre, pas encore postulé
  • 🟡 En attente — vous avez postulé, en attente de réponse
  • 🟣 Relance prévue — une relance est programmée
  • 🟠 Entretien — vous avez décroché un entretien
  • 🟢 Acceptée — offre acceptée 🎉
  • 🔴 Refusée — candidature refusée
  • ⚫ Abandonnée — vous avez laissé tomber

Comment changer le statut ?

  • Dans la fiche détail : cliquez sur le nouveau statut dans la colonne de droite
  • Dans le Kanban : glissez-déposez la carte dans une autre colonne
  • Dans le Tableau : cliquez sur le badge statut et choisissez le nouveau
🎉 Quand vous passez une candidature en « Acceptée », une petite animation de félicitations apparaît !

7. Gérer les relances

Les relances vous aident à ne pas oublier de recontacter une entreprise.

Programmer une relance

Quand vous créez une candidature, vous pouvez choisir :

  • Dans combien de jours relancer (3, 5, 7, 10, 14 jours ou personnalisé)
  • Combien de fois maximum (1, 2, 3 ou illimité)

Faire une relance

Quand le jour arrive, l'application vous le signale (dans les notifications 🔔 et sur le Dashboard). Allez sur la fiche détail et cliquez sur « Relance effectuée ». La prochaine relance est automatiquement reprogrammée.

8. Organiser avec le Kanban

Le Kanban ressemble à un tableau Trello avec des colonnes. Chaque colonne = un statut.

  • Glissez-déposez une carte d'une colonne à l'autre pour changer son statut
  • Cliquez sur une carte pour ouvrir sa fiche détail
  • Idéal pour visualiser d'un coup d'œil où en sont toutes vos candidatures

9. La vue tableau

Une vue plus classique, comme un tableur :

  • Trier en cliquant sur les en-têtes (Entreprise, Poste, Date, Statut)
  • Rechercher avec la barre de recherche (tapez un nom d'entreprise, un poste...)
  • Filtrer par statut ou par méthode de candidature
  • Changer le statut directement en cliquant sur le badge

10. Le calendrier

Le calendrier vous montre :

  • 📨 Quand vous avez postulé (en bleu)
  • 🔄 Quand relancer (en violet)
  • 🎯 Quand sont vos entretiens (en orange)

Naviguez entre les mois avec les flèches ◀ ▶.

11. Comparer ses offres

La page Négociation (accessible depuis le menu) vous permet de comparer vos offres acceptées.

Si vous avez plusieurs offres, vous voyez :

  • Le salaire de chaque offre
  • 🏆 Laquelle est la mieux payée
  • Les technologies, le lieu, le télétravail
  • Des conseils de négociation
💡 Pensez à indiquer si l'offre est rémunérée et à quel montant quand vous créez votre candidature. C'est ce qui alimente cette page.

12. Le compte à rebours

Dans la barre du haut, vous voyez un petit badge « Compte à rebours ». Il concerne les stages et alternances.

Définir une date de début

  1. Cliquez sur « Compte à rebours » dans la barre du haut
  2. Choisissez la date de début de votre stage ou alternance
  3. Cliquez sur Valider

Ce que vous voyez

Une fois la date définie, le badge devient coloré et affiche le temps restant :

  • 🟢 Vert = c'est aujourd'hui !
  • 🟠 Orange = dans 7 jours ou moins
  • 🔵 Bleu = dans plus de 7 jours

Exemple : 15/09 −2 mois 15 jours ou −45 jours ou Aujourd'hui.

Modifier ou réinitialiser

  • Modifier : cliquez sur le badge → changez la date → Valider
  • Réinitialiser : cliquez sur le badge → bouton « Réinitialiser »

Le compte à rebours se met à jour tout seul.

13. Suivre les entreprises

La page Entreprises vous permet de garder une fiche par entreprise avec :

  • Le nom, le secteur, la taille
  • Les contacts RH et recruteurs
  • Toutes les candidatures que vous avez envoyées chez cette entreprise

Cliquez sur « Ajouter une entreprise » pour commencer.

14. Les réglages

Apparence

  • Mode sombre / clair
  • Couleur du thème — 6 couleurs au choix, tout change instantanément

Relances par défaut

  • Délai avant la première relance
  • Nombre maximum de relances

Format des dates

Choisissez entre JJ/MM/AAAA, MM/JJ/AAAA ou AAAA-MM-JJ.

Sauvegarder et restaurer

  • Exporter JSON — sauvegarde complète de toutes vos données
  • Exporter CSV — pour ouvrir dans Excel
  • Importer JSON — restaurer une sauvegarde

15. Astuces

  • 📂 Séparez bien vos catégories — Stage, Alternance, CDI, CDD. Les statistiques sont calculées séparément pour chacune.
  • ⏰ Utilisez les relances — programmez-en une 7 jours après avoir postulé pour ne pas oublier de recontacter.
  • 💰 Indiquez le salaire quand l'offre est rémunérée. Ça vous servira pour comparer vos offres plus tard.
  • 🖱️ Glissez-déposez dans le Kanban — c'est le moyen le plus rapide de changer un statut.
  • 💾 Exportez de temps en temps — faites un export JSON dans les Paramètres pour sauvegarder vos données.
  • 🎨 Changez la couleur du thème dans les Paramètres si le violet ne vous plaît pas.
  • 📅 Ajoutez vos dates d'entretien — elles apparaîtront sur le calendrier.
